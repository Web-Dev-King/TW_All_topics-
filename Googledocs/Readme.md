# Google Docs — Complete Class Notes

**Google Docs** is a cloud-based word processor used for real-time collaborative technical writing, report formatting, reviewing, and document sharing.

---

## 1. Document Structuring & Formatting
* **Paragraph Styles:** Use built-in styles (`Title`, `Subtitle`, `Heading 1`, `Heading 2`, `Heading 3`, `Normal text`) rather than manually resizing fonts.
* **Document Outline & Navigation:** Headings automatically populate the left **Document Outline** sidebar for quick jumping across long reports.
* **Table of Contents (ToC):** Insert via **Insert > Table of contents** (with page numbers or clickable blue links) and update with one click.
* **Page Setup:** Configure margins, page orientation (`Portrait` / `Landscape`), paper size (`A4` / `Letter`), and pageless mode under **File > Page setup**.
* **Headers, Footers & Page Numbers:** Add running titles, author names, and dynamic page numbers via **Insert > Headers & footers** and **Insert > Page numbers**.

---

## 2. Technical Content Elements
* **Tables:** Insert structured tables (**Insert > Table**) with customizable cell shading, borders, merged cells, and pinned header rows.
* **Equations & Special Characters:**
  * Insert mathematical formulas using **Insert > Equation** (supports fractions, Greek letters, roots, integrals, and superscripts/subscripts).
  * Insert symbols via **Insert > Special characters**.
* **Code Snippets & Callouts:** Format code using monospace fonts (`Consolas`, `Courier New`, or `Roboto Mono`) inside single-cell shaded tables or **Building blocks > Code blocks**.
* **Images & Drawings:** Insert diagrams from local files, Google Drive, or build flowcharts directly using **Insert > Drawing > New**.
* **Smart Chips (`@` Menu):** Type `@` to quickly insert dates, people tags, file links, dropdown status badges, or meeting notes.

---

## 3. Collaboration & Review Workflow
* **Sharing & Access Permissions:** Click **Share** to invite teammates via email or link with three permission levels:
  * **Viewer:** Can only read and download the document.
  * **Commenter:** Can highlight text and leave comments/suggestions, but cannot edit directly.
  * **Editor:** Full access to modify text, formatting, and sharing settings.
* **Editing Modes (Top-Right Toolbar):**
  * **Editing Mode:** Directly modifies the document text.
  * **Suggesting Mode:** Tracks all insertions and deletions as colored suggestions for team approval (similar to *Track Changes* in MS Word).
  * **Viewing Mode:** Read-only preview without accidental edits.
* **Comments & Action Items:** Highlight any text (`Ctrl + Alt + M`) to add feedback, tag teammates with `@email`, and resolve threads once fixed.

---

## 4. Version History & Offline Access
* **Version History (`Ctrl + Alt + Shift + H`):**
  * Automatically tracks every edit made by every collaborator over time.
  * Allows naming milestone versions (e.g., *"Draft 1"*, *"Final Submission"*), comparing changes, and restoring older versions.
* **Offline Editing:** Enable offline sync via Google Drive settings to view and edit documents without an active internet connection.

---

## 5. Academic Writing & Export Tools
* **Citations Tool (**Tools > Citations**):** Manages bibliography sources (Books, Websites, Journals) in **APA**, **MLA**, or **Chicago** format and generates a formatted *Works Cited / References* section.
* **Footnotes (`Ctrl + Alt + F`):** Adds numbered explanatory notes or references at the bottom of the page.
* **Word Count (`Ctrl + Shift + C`):** Displays total pages, words, characters, and characters excluding spaces.
* **Export & Download Formats (**File > Download**):**
  * `.pdf` (PDF Document — standard for final report submission)
  * `.docx` (Microsoft Word)
  * `.odt` (OpenDocument Format)
  * `.txt` / `.rtf` / `.md` (Plain text, Rich Text, or Markdown)
  * `.html` / `.epub` (Web page or e-book)

---

## 6. Quick Comparison: Google Docs vs. LaTeX

| Feature | Google Docs | LaTeX |
| :--- | :--- | :--- |
| **Interface** | WYSIWYG (What You See Is What You Get) | Plain-text markup & compiler |
| **Collaboration** | Real-time multi-user editing & comments | Git / Overleaf version control |
| **Complex Math** | Basic built-in equation editor | Industry-standard math typesetting |
| **Best Used For** | Team drafts, fast reports, peer reviews | Research papers, theses, heavy math |
